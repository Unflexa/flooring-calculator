# FlooringCalculator

![build](https://github.com/ТВОЙ-НИК/flooring-calculator/actions/workflows/build.yml/badge.svg)

Библиотека для расчёта количества напольных покрытий: площадь, запас на подрезку, упаковки, плинтус, подложка.

## Сборка и тесты локально

```bash
git clone https://github.com/ТВОЙ-НИК/flooring-calculator.git
cd flooring-calculator
dotnet build
dotnet test
```

Статус: в разработке, план — 7 итераций (см. Issues).
